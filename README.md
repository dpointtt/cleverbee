# CleverBee

CleverBee - a digital monitoring system for honey bee colonies.
IoT sensors (measuring weight, temperature, humidity, and acoustics) are connected to the beehives and transmit readings on a regular basis.
Based on this data, the beekeeper can remotely assess the condition of a colony, identify risks (such as overheating, weight loss, or swarming), and plan hive inspections.

This is prototype project made for university assignment.
